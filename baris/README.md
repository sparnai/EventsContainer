# Baris Flight Tracker

Baris Flight Tracker is an Android application that tracks Ryanair flight prices between Vilnius (VNO), Turin (TRN), Bari (BRI), Vienna (VIE), and Bergamo (BGY).

It allows you to easily view the latest prices and flight times for multiple segments on your phone. The app checks prices for free directly through the public Ryanair API.

## Features
- Real-time flight price tracking
- Multiple segments tracking for different travel options
- Material Design 3 interface
- Built with Kotlin and Jetpack Compose

## Building
1. Open the project in Android Studio.
2. Build and run the app on an emulator or physical device.
